# BobClawblaw Homebrew Tap

## DropConvert

```sh
brew trust bobclawblaw/tap
brew install --cask bobclawblaw/tap/dropconvert
```

DropConvert is a macOS menu-bar video, audio, and image converter with yt-dlp link downloads. The cask installs
`ffmpeg` and `yt-dlp` as dependencies. Updates: `brew upgrade --cask dropconvert`.
